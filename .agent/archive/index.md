## 1. How to Maintain This Index

Update this file whenever you move memory into `.agent/archive/`.

Archive rules:

- Store archived memory in `.agent/archive/yyyy/qN.md`.
- Keep archive files concise and sectioned.
- Use lowercase kebab-case keywords.
- Include the original memory date when known.
- Remove or mark the moved entry from `.agent/memory/index.md` in the same change.
- Prefer targeted search (`rg`) over loading full archive files.
